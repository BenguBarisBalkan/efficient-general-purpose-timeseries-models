# Anomaly detection — SparseTSF

Reconstruction-based detection with sliding window 100; metric = **point-adjusted F1** (the standard
protocol — `utils/tools.py::adjustment` expands a detected point to its whole anomalous segment
before scoring). Generated by `benchmarks/run_anomaly_benchmarks.py` (idempotent).

- SparseTSF reconstructs each window with its cross-period head, so `period_len=25` (divides
  `seq_len=100`). Config: `lr=1e-4`, 3 epochs, batch 128; `anomaly_ratio` 1.0 (0.5 for SMD) sets the
  score threshold percentile.
- **Dataset availability** (see `benchmarks/tools/fetch_task_datasets.py`): PSM and SMD are fetched
  automatically from open sources. **MSL / SMAP** need the TimesNet/TSLib preprocessed `.npy` bundle
  — the original telemanom S3 download now returns HTTP 403, so they are not runnable here.
  **SWaT** is gated behind the iTrust (SUTD) request form. Those rows read `NOT AVAILABLE`.
- **Only SparseTSF is run locally.** The `TimeMixer++ F1 (paper)` column and the average reference
  rows are *published* values (ICLR'25 paper, Table 12 / Fig. 3), not re-run here. Note the paper's
  average is over all five datasets, so it is not directly comparable to an average over a subset.
