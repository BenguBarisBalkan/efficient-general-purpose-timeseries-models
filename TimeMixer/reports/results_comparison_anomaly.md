# Anomaly detection — SparseTSF and TimeMixer

Reconstruction-based detection with sliding window 100; metric = **point-adjusted F1** (the standard
protocol — `utils/tools.py::adjustment` expands a detected point to its whole anomalous segment
before scoring). Generated by `benchmarks/run_anomaly_benchmarks.py` (idempotent).

- SparseTSF reconstructs each window with its cross-period head, so `period_len=25` (divides
  `seq_len=100`). Config: `lr=1e-4`, 3 epochs, batch 128; `anomaly_ratio` 1.0 (0.5 for SMD) sets the
  score threshold percentile.
- **Dataset availability** (see `benchmarks/tools/fetch_task_datasets.py`): PSM and SMD are fetched
  automatically from open sources. **MSL / SMAP** are rebuilt from a hand-downloaded Kaggle mirror
  of NASA's original release (the telemanom S3 download now returns HTTP 403); the rebuilt sizes
  equal the published ones exactly, and their anomaly rates are slightly below the commonly cited
  figures (see `datasets_reference.md`). **SWaT** is gated behind the iTrust (SUTD) request form, so
  its rows read `NOT AVAILABLE`.
- **SparseTSF and TimeMixer are both run locally**, same machine and same training protocol.
  TimeMixer publishes no anomaly-detection settings (neither its repository nor the
  Time-Series-Library ships any), so it uses its own ETTh1 long-term architecture
  (`benchmarks/tm_config.py`: 2 layers, d_model 16, 3 scales; 62,573 parameters on PSM against
  SparseTSF's 41). Read its row as a local reference without a published configuration.
- Over the four available datasets the result is mixed. **TimeMixer has the higher F1 on three of
  them** (PSM 96.72 against 95.26, SMD 84.18 against 80.02, SMAP 73.05 against 66.76), but **SparseTSF
  has the higher average** (79.96 against 75.49). That is entirely due to MSL, where the untuned
  TimeMixer catches only a third of the anomalies (recall 34.12, F1 48.02 against SparseTSF's 77.80).
  On SMD and SMAP the gap to TimeMixer is mostly recall: SparseTSF reconstructs anomalies too
  faithfully, the identity-map problem examined in `results_sparsetsf_plus_anomaly.md`.
- Over the same four datasets the published TimeMixer++ figures average 85.75, so SparseTSF is 5.8
  points behind and the untuned local TimeMixer 10.3 points behind.
- The `TimeMixer++ F1 (paper)` column and the average reference rows are *published* values (ICLR'25
  paper, Table 12 / Fig. 3). The paper's average is over all five datasets, so it is not directly
  comparable to an average over a subset.
