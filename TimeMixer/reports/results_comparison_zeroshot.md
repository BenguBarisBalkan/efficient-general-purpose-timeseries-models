# Zero-shot (cross-dataset transfer) forecasting — SparseTSF

Train on dataset **A**, evaluate on unseen dataset **B** with no further training, over the 6 ETT
transfer pairs. `seq_len=96`, `pred_len ∈ {96,192,336,720}`, MSE/MAE. Generated by
`benchmarks/run_zeroshot_benchmarks.py` (idempotent).

- Implemented by training on A, copying A's checkpoint into B's `setting` directory, then running B
  with `--is_training 0` (test-only). The model never sees B's training data.
- SparseTSF's linear layer has shape `(seq_len/period_len → pred_len/period_len)`, so the **source**
  dataset's `period_len` is reused for the target — otherwise the checkpoint would not load. All
  `pred_len`s here are divisible by both 24 and 4, so every pair is valid.
- **Only SparseTSF is run locally.** TimeMixer / TimeMixer++ columns are the *published* values from
  the TimeMixer++ paper (ICLR'25, Table 6), in italics — reference points, not like-for-like runs.
