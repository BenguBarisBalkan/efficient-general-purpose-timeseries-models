# PEMS multivariate short-term forecasting — SparseTSF

Four traffic-network datasets (PEMS03/04/07/08), input **96 → predict 12**, metrics **MAE / MAPE /
RMSE** on the original (inverse-transformed) scale. Lower is better. Generated by
`benchmarks/run_pems_benchmarks.py` (idempotent).

- Config: `use_norm=0` and `task_name=long_term_forecast` (both follow the upstream PEMS scripts —
  the short-term exp class is M4-specific). SparseTSF: `period_len=12` (= 1 hour of 5-min data; it
  must divide both `seq_len=96` and `pred_len=12`), `lr=0.01`, 10 epochs, batch 16.
- **Only SparseTSF is run locally.** TimeMixer / TimeMixer++ rows are the *published* averages from
  the TimeMixer++ paper (ICLR'25, Table 3), in italics for context — not re-run here, and tuned by
  their authors, so treat them as a reference point rather than a like-for-like comparison.
- MAPE comes from `utils/metrics.py`, which zeroes relative errors > 5 before averaging; reported
  here as a percentage.
